# EuroPilot

EuroPilot is an early-stage concept for an AI-assisted payment incident investigation and reconciliation platform. The initial MVP is a synthetic-data, read-only investigation workflow; it does not execute payments or move money.

This repository currently contains the Phase 0 documentation foundation. Architecture and implementation choices remain subject to owner approval.
