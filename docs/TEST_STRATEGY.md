# Test Strategy

Status: Proposed; no application tests exist.

Planned layers are domain unit tests; persistence/integration tests; API contract, validation, authorization, and pagination tests; frontend component/accessibility tests; selected Playwright journeys; security-negative tests; and repeatable performance checks. Scenarios must include duplicate/replayed, late/out-of-order, malformed, unknown, conflicting, timeout, retry, correlation, concurrency, and missing-evidence cases.

Commands are not yet defined because no toolchain is installed or approved. Future reports must use `Command`, `Result`, and `Evidence`; no test result is claimed in Phase 0.
