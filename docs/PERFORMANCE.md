# Performance

Status: Proposed goals; no benchmark exists.

Keep list queries bounded and paginated, avoid N+1 queries and unnecessary UI work, and keep AI calls out of request-critical paths where appropriate. Targets must be set only after the dataset, environment, workload, and measurement method are approved. No benchmark or performance guarantee is claimed.

Open approvals: expected dataset size, response-time/error targets, concurrency, and observability.
