# UI/UX Specification

Status: Proposed; no frontend implemented.

The proposed interface is a trustworthy operations workspace with investigation list/detail views, evidence timelines, source/type/timestamp visibility, filters, pagination, and explicit missing/unknown/conflict states. Unknown must not resemble confirmed success or failure.

Provide loading, empty, partial, error, retryable, and successful states. Use semantic HTML, keyboard navigation, visible focus, labels, contrast, and non-color status cues. A restrained navy/dark direction is proposed; tokens and component choices require approval.

Open questions: primary operator workflow, responsive priorities, information density, and final design system.
